# Contributing

Cam on ban da quan tam den du an nay.

## Bat dau

```bash
npm install
npm run dev
```

## Quy trinh

1. Fork repo va tao branch tu `main`
2. Dat ten branch theo dang `feat/...`, `fix/...`, `chore/...`, `docs/...`
3. Commit theo [Conventional Commits](https://www.conventionalcommits.org/)
4. Chay `npm run lint` va `npm run build` truoc khi mo PR
5. Mo pull request va mo ta ro thay doi

## Bao loi

Vui long dung issue template va kem theo cac buoc tai hien loi.
